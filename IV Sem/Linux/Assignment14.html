Bash scripting — real-world assignment

Each question describes a practical situation. Write a shell script that solves it. Test your script with different inputs before submitting.

Q1

ATM PIN entry

You are building a simple terminal-based banking kiosk.

The script should greet the user by name (entered visibly) and then ask for their PIN (hidden input). If the PIN is exactly 4 digits, print "Access granted" in green. If it is not 4 digits, print "Invalid PIN format" in red.

A utility company wants a quick script for field agents to estimate bills on-site.

Q3

Hospital triage classifier

A clinic needs a quick command-line tool to assign patient priority levels.

Ask for the patient's reported pain score (1–10). Print "Critical — see doctor immediately" for 8–10, "Moderate — wait for next available slot" for 4–7, and "Mild — take a seat" for 1–3. Reject any value outside that range with an error.

Server health dashboard

A junior sysadmin needs a single script to check if a server is healthy before a deployment.

Display a bold blue header line, then print: current uptime, available RAM, top 3 CPU-consuming processes, and whether a web server (nginx or apache2) is active. Separate each section with a styled divider line.

Software installer wizard

Your team ships a tool that must be installed differently depending on the operating system.

Ask the user which OS they are running. Use a case statement to print the correct install command: Homebrew for Mac, apt for Debian/Ubuntu, dnf for RHEL/CentOS (use fall-through so both map to the same instruction), and an unsupported message for anything else.

Disk space alert

A hosting company wants an automated check that warns when a drive is running low.

Read the current disk usage percentage for the root partition using df. Strip the % symbol to get a plain integer. If usage is above 80%, print a bold red warning. If between 60–80%, print a yellow caution. Otherwise print a green "All clear".

Q10

Automated backup checker

A DevOps team runs nightly backups and needs a morning script to verify the latest backup file exists and is usable.

Ask the user for the backup directory path. Check if the directory exists. If it does, find and print the name and size (in KB) of the most recently modified file inside it. If the directory is missing or empty, print a formatted alert in red and exit with a non-zero status code.
